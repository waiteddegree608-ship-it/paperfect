## 参考工作流的吸收

参考文献目录中的实现采用逐页视觉翻译、正文重排、表格重建、原始裁片保留、图内文字替换以及带证据记录的论文解读。本轮将这些机制重新实现为项目内服务，不依赖原目录中的私人脚本、固定论文列表或绝对路径。

保留了一个重要区分：中文 SVG 是原图底图与文字覆盖层；原始 PDF 区域导出的 SVG 则保留源文件已有矢量。两者都可以作为素材，但不能宣称整张科学配图已被重绘为完全可编辑的矢量。

## 验证边界

尚未用真实付费模型对参考论文进行逐页质量对比，也没有声称达到参考目录的最终人工修订质量。尚未重新生成安装包，现有产品安装文件仍是旧构建。新界面和新服务需要从源码运行或完整重建后使用。

当前服务协议为 Chat Completions。参考脚本中采用 Responses 的模型不能仅凭名称保证在这里直接使用，应选兼容端点或后续增加协议适配。长文讲解已经分块覆盖提取文字，PPT 规划为有标记的页级摘录；扫描论文、复杂公式和图表仍需 OCR 或视觉核查。

自有代码使用用户选择的 MIT。第三方依赖许可保留，见 `THIRD_PARTY_NOTICES.md`。当前仓库历史未清理、未改写、未推送；后续开源可先审阅干净源码导出，再决定发布方式。
