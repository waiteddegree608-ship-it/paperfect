# Shipped prompt files

Stem = `prompt_type`. Chinese bodies below; English variants are `*_en.md` in the same folder.

## 提示词汇总

1. 提取核心研究背景、主要贡献、创新点。
2. 详细分析方法论：模型、算法或实验设计。
3. 梳理实验结果与结论，证明了什么假设。
4. 讨论局限性与未来方向。

## 计算机+人工智能

1. 研究内容、解决的困难、相关现状、创新点、作者工作。
2. 按文章顺序翻译并解读全文。
3. 是否为「大模型 A + 模块 b/c 缝合」？列出模块，说明消融如何证明 A+b+c 优于 A。
4. 讲解框架图及每个模块的实现方式（现成模型缝合 / 自训练等）。

## 默认

1. 研究内容、困难、现状、创新点、作者工作。
2. 按文章顺序翻译并解读。
